# 使用 VOFA+ 调 PID

平衡环和速度环的参数可以在运行中通过 VOFA+ 修改，下一拍控制循环即生效。修改只写在 RAM 里，复位或重新上电后恢复 `Core/Src/pid_balance.c` 中的初值。调完后把满意的数值抄回该文件再编译。

实现见 `Application/Vofa.c`、`Application/Vofa.h`。主循环在 `Core/Src/main.c` 里调用 `Vofa_PidTune_Poll()`。

## 连接

| 项目 | 值 |
|------|-----|
| 外设 | USART1（PA9 TX，PA10 RX） |
| 波特率 | 115200 |
| 数据位 / 停止位 / 校验 | 8 / 1 / 无 |
| 上传协议 | JustFloat（小端 float，帧尾 `00 00 80 7F`） |
| 下发协议 | ASCII 文本，以 `!`、`\r` 或 `\n` 结束 |

VOFA+ 中把引擎选成 **JustFloat**，端口和波特率与上表一致。上传和调参共用这一路串口：波形走发送，命令走接收，拖滑块不会打乱波形。

正常平衡模式才能调参。`Core/Src/main.c` 里 `RUN_ENCODER_TEST`、`RUN_MPU_TEST`、`RUN_ACCEL_CAL` 都要为 `0`。

## 波形通道

主循环每收到一帧有效姿态就上传 4 个 float：

| 通道 | 变量 | 含义 |
|------|------|------|
| 0 | `BalancePID.SetVal` | 俯仰目标角（机械零点 + 速度环修正），单位度 |
| 1 | `BalancePID.NowVal` | 当前俯仰角 `pitch`，单位度 |
| 2 | `gyro_filt` | 低通后的俯仰角速度，单位 °/s |
| 3 | `pid_balance` | 平衡环输出，再乘 9 变成电机占空比 |

在 VOFA+ 里添加波形图控件，通道数设为 4。通道 0 和通道 1 重合，表示角度环跟上了目标。

## 命令

在 VOFA+ 左侧「命令」里新增一条，名字自定，内容用下表。`%.3f`、`%.1f`、`%.2f` 是占位符，控件发送时会被当前值替换。`!` 是结束符，不要删。

| 命令内容 | 写入 | 上电初值 | 说明 |
|----------|------|----------|------|
| `BK=%.3f!` | `BalancePID.Kp` | 3.9 | 平衡环比例 |
| `BI=%.3f!` | `BalancePID.Ki` | 0 | 平衡环积分。初值为 0，不参与运算 |
| `BD=%.3f!` | `BalancePID.Kd` | 0.25 | 平衡环微分，乘的是俯仰角速度 |
| `BMAX=%.1f!` | `BalancePID.MaxOut` / `MinOut` | ±100 | 输出限幅，取绝对值后正负对称 |
| `BILIM=%.2f!` | `BalancePID.MaxI` | 3 | 积分限幅，取绝对值 |
| `SK=%.3f!` | `SpeedPID.Kp` | 0.17 | 速度环比例 |
| `SI=%.3f!` | `SpeedPID.Ki` | 0.005 | 速度环积分 |
| `SD=%.3f!` | `SpeedPID.Kd` | 0.02 | 速度环微分 |
| `SMAX=%.1f!` | `SpeedPID.MaxOut` / `MinOut` | ±10 | 速度环输出限幅，单位度，叠加到俯仰目标 |
| `SILIM=%.2f!` | `SpeedPID.MaxI` | 5 | 速度环积分限幅，取绝对值 |
| `ST=%.2f!` | `speed_target_rpm` | 0 | 速度目标，输出轴 RPM。0 表示原地平衡 |

字母不区分大小写。`BILIM` 要写全，不要写成 `BI`。

没有滑块时，也可以在 VOFA+ 的发送框里直接发，例如 `BK=4.2` 然后回车。

发送 `?` 或 `GET` 会回读一行当前参数，格式与上表的键名一致。这一行是普通文本，JustFloat 波形会闪一下，不要绑到会连续发送的控件上。

## 控件

1. 在命令页按上表把要用的命令都建好。
2. 添加滑块（或微调框）。右键设置最小值、最大值、步进和小数位数。建议范围不要比上电初值宽太多，避免一拖就把车推倒。
3. 右键控件，绑定对应命令。
4. 发送时机选「鼠标松开后发送」。拖动过程中连续发送会让参数台阶式变化，车更容易晃。
5. 控件布局和命令可以保存到 VOFA+ 工程，下次不用重配。

建议的控件：

- 波形图：4 通道，看目标角、实际角、角速度、平衡环输出。
- 平衡环：`BK`、`BD`，需要积分时再加 `BI`。
- 速度环：确认角度环能站住之后，再加 `SK`、`SI`、`SD` 和 `ST`。

## 调参顺序

1. 先只动平衡环。`ST=0`，速度环保持较小，让车以原地平衡为主。
2. 看通道 0 和通道 1。比例太小会扶不住，太大会来回晃。微分用来压角速度，过大则会把噪声放大成电机抖动。
3. 角度环稳定后，用 `ST` 给一个小转速，再调速度环。速度环的输出是角度修正，`SMAX` 限制它最多把俯仰目标推开多少度。
4. 把最终数值写回 `Core/Src/pid_balance.c` 里 `BalancePID`、`SpeedPID` 的初值，以及 `speed_target_rpm`。

摔倒保护触发后电机会停，但串口命令仍然有效。重新站稳时 `PID_Init()` 只清积分和误差，不清本次调好的 Kp / Ki / Kd。

## 注意

- `BI` 写成非 0 后，平衡环输出变为 `Kp×角度误差 + Ki 积分 − Kd×角速度`。再把 `BI` 写成 0 会清掉已经积累的积分。
- 平衡环微分用的是函数参数里的角速度。`main.c` 里目前是 `PID_BalanceGyro(&BalancePID, 0)`，角速度被固定为 0，此时改 `BD` 不会改变电机输出。要把实参改回 `gyro_filt`，`BD` 才会起作用。
- `BMAX`、`SMAX`、`BILIM`、`SILIM` 按绝对值使用。发送 `-100` 和发送 `100` 的限幅相同。
- 不要在调参的同时往这条串口打大量 `printf`。文本和 JustFloat 帧混在一起时，波形会错位。
